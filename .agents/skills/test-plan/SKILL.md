# EduSense Test Plan

## Workflow
1. Read the relevant Proposal, SRS, User Stories, and architecture docs in docs/.
2. Identify inconsistencies, missing acceptance criteria, and assumptions.
3. Map features to risks and test objectives.
4. Define scope, exclusions, test levels, test types, and environment.
5. Create traceability between requirements and test cases.
6. Prioritize authentication, authorization, data integrity, and AI failure paths.
7. Include RAG retrieval, citation correctness, and essay grading behavior.
8. Define measurable pass/fail criteria only when supported by requirements.
9. Record unresolved decisions instead of inventing thresholds.

## Expected Sections
- Objectives and scope
- Test strategy
- Test environment and tools
- Feature and risk coverage
- Entry and exit criteria
- Test data and dependencies
- Defect management
- Requirement traceability
- Risks, assumptions, and open questions
